# 💌 모바일 청첩장 | Weddingmoment
나만의 특별한 청첩장 페이지를 만들 수 있는 Next.js 기반 프로젝트입니다.

## ✨ Features
### 💍 청첩장 전용 페이지: 모바일 최적화된 디자인

### 📆 일정 및 장소 정보 안내

### 🖼️ 갤러리와 연애 스토리 공유

### 💬 하객 메시지 작성 기능

### 📱 모바일에서 바로 공유

## 🛠️ Tech Stack
Framework: Next.js

Language: TypeScript

Styling: TailwindCSS

Deployment: Vercel

## 🚀 Getting Started
로컬 개발 서버 실행:
```
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
브라우저에서 http://localhost:3000을 열어 확인할 수 있습니다.
